# IDD-0003.spec-host-controls-and-presentation

## Intent

Give an in-person moderator clear, touch-friendly controls while keeping role information appropriately concealed and auxiliary controls independent from game rules.

## Related Specifications

- IDD-0001 defines access and participant identity.
- IDD-0002 owns phase, voting and outcome semantics.
- IDD-0004 owns durable game state and correction.

## Behavior
