# La Verdad club logo

A dark-charcoal and warm-gold club seal, using the application's existing fedora silhouette with a new outlined La Verdad wordmark and double-ring frame.

## Files

- **la-verdad-logo.svg** — scalable vector master, with transparent outer corners and lettering converted to paths. Recommended for **Header logo**. No external images, fonts, or scripts.
- **la-verdad-logo.png** — 1024 × 1024 PNG version of the same seal, with transparent outer corners. Alternative for **Header logo**.
- **la-verdad-card.png** — 1024 × 1024 PNG with a dark background and additional crop-safe padding. Recommended for **Playing-card logo**.

## Manual upload

1. Open your club in the application.
2. Open **Manage → Edit club** (Russian: **Изменить клуб** in the management menu).
3. Select the SVG or transparent PNG in **Header logo / Логотип в шапке**.
4. Select `la-verdad-card.png` in **Playing-card logo / Логотип игральной карты**.
5. Inspect the previews, then choose **Save club / Сохранить клуб** when you want to apply them.

All three files were rendered and checked. Their serialized data URLs are below the current 1,500,000-character per-logo limit. File-picker previews, the actual small header, and desktop/narrow card crops were checked in Chrome and WebKit using isolated API fixtures. No real club was saved, no existing logo was replaced, and the application icon is unchanged.
