# Issue 32 Verified Delivery Plan

> **For Hermes:** Execute only after the immutable-candidate qualification plan has passed in full and an independent reviewer has approved the exact candidate tree.

**Goal:** Deliver the already-qualified issue-32 tree to `origin/main` and close GitHub issue #32 with verified, read-back evidence.

**Architecture:** Keep delivery mechanically separate from qualification. Reconcile `main`, prove that the index still equals the approved tree, create one closeout commit containing only the plan-lifecycle deletions, verify the commit tree, push directly to `origin/main`, verify the remote SHA, then publish exact local evidence and close #32 last.

**Tech Stack:** Git, GitHub CLI, repository-local evidence captured by the qualification run.

**Plain-language summary:** After the exact code tree passes every local and independent gate, we will commit only the completed-plan cleanup, push that qualified tree to `main`, verify GitHub received the same commit, and close #32 with the real check results.

**Non-goals:** Re-running implementation work; changing the frozen candidate; opening a PR; waiting for CI; closing #17 or #23; modifying deployment state; staging the unrelated untracked plan; claiming test totals or results not taken from actual output.

## Delivery acceptance criteria

- The commit tree equals the independently approved and locally qualified `candidate_tree`.
- `origin/main` equals the local commit SHA after fetch.
- No force push, PR, CI wait, deployment, or unrelated staging occurs.
- The GitHub evidence comment is read back before closure and contains only actual results.
- #32 is read back as completed/closed after the comment is verified.
- The unrelated untracked plan remains untouched.

## Risks and stop conditions

- Any post-qualification file edit invalidates approval and blocks delivery.
- Remote divergence, a closed/changed issue, or an unexpected staged path blocks push/closure.
- A successful `git push`, comment, or `gh issue close` response alone is insufficient; each target must be read back.
