# Role-draw status placement implementation plan

**Goal:** Display role-draw status without a stray element border behind the timer.
**Summary:** Remove the overlapping status-box footprint while keeping the remaining-role count clearly visible beside the game-stage information.
**Architecture:** Give the role-draw status an explicit header slot consistent with the responsive game header; do not alter timer/media panel behavior.
**Tech stack:** React markup, CSS responsive layout, browser DOM inspection.
**Non-goals:** Removing useful progress information, timer redesign, music-player changes, broad z-index escalation.
